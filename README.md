# Andromeda Light - a multipurpose SaaS landing page theme built with NextJS and Tailwind CSS, designed to showcase any SaaS product with elegance and functionality. 
#### Preview

 - [Demo](https://themewagon.github.io/andromeda/)

#### Download
 - [Download from ThemeWagon](https://themewagon.com/themes/andromeda/)

## Getting Started

1. Clone Repository
```
git clone https://github.com/themewagon/andromeda.git
```
2. Install Dependencies
```
npm i
```
3. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
